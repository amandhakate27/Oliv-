# OLIV (Branding Agency)

A modern HTML/CSS branding agency landing page.

> Assignment-A5: Practicing UI by @sharyians Coding School

## Overview

This project is a learning exercise in layout, flexbox, CSS animations. It showcases a professional branding agency website with smooth animations and modern UI patterns.

## Pages

- `index.html` — Main landing page with hero, services, and portfolio sections
